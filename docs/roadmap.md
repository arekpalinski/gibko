# Roadmap

## Phase 1: Clickable Prototype

- PWA shell.
- Local profile.
- Local progress.
- First rainforest chapter with 18 adventures.
- Energy leaves, day path, badges.
- Basic install prompt.
- Progress tests for unlocking, timing-based rewards, ratings, badges, and local data.

## Phase 2: Better Exercise Content

- Review real stretching exercises.
- Create a safer progression model.
- Refine the first chapter adventures after real use.
- Add clearer exercise illustrations or animations.

## Phase 3: More Game Feel

- Add collectibles.
- Add richer chapter completion moments.
- Add daily adventure variety.
- Add optional sound and motion settings.

## Phase 4: More Chapters

- Add the second forest chapter with a different theme.
- Keep chapter data compatible with the first chapter model.
- Reuse exercise definitions where possible while allowing chapter-specific adventure flavor.
