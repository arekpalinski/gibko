# PWA Notes

## Hosting

The app is configured for GitHub Pages project hosting:

```text
https://arekpalinski.github.io/gibko/
```

Vite uses:

```ts
base: '/gibko/'
```

## Installability

Android Chrome is the first target. The app includes:

- Web app manifest.
- Standalone display mode.
- Theme and background colors.
- PWA icons.
- Service worker generated by `vite-plugin-pwa`.
- Custom install prompt support through `beforeinstallprompt`.

## Routing

The app uses `HashRouter` to avoid GitHub Pages refresh problems for client-side routes.

## Offline

The current goal is app-shell offline behavior after installation. Full content sync or backend behavior is out of scope.
