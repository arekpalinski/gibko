# Game Design

## Tone

Gibko should mix silly, motivating, and occasionally educational language. The app should avoid shame, pressure, and failure framing.

## Progression

- Missions unlock in order.
- Completed missions can be repeated.
- Replays still grant XP because movement is valuable.
- Streaks are gentle and should not create pressure.

## Rewards

- XP after every mission.
- Badges for milestone and bonus achievements.
- Future versions may add collectibles, avatar accessories, or world items.
